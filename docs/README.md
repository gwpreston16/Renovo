# Renovo documentation

Every page of Renovo's documentation, one line each. The
[project README](../README.md) is the front page: what Renovo is, what it looks
like, and how to start it.

## Running an instance

- [install.md](install.md): the quick start in full, the two Compose stacks,
  MySQL/MariaDB, and running without Docker.
- [upgrading.md](upgrading.md): upgrading an instance (back up first).
- [configuration.md](configuration.md): the environment variables.
- [operations.md](operations.md): console commands, the scheduler and cron,
  health and metrics, backup and restore, and demonstration mode.

## Using it

- [features/tracking.md](features/tracking.md): the dashboard, the
  subscriptions list and form, invoices and receipts, and importing.
- [features/money.md](features/money.md): analytics, exchange rates, price
  history, trials, budgets, the forecast, shared costs and year over year.
- [features/notifications.md](features/notifications.md): channels, when
  reminders arrive, and where they may be sent.
- [features/households.md](features/households.md): households and people,
  and roles and data isolation.
- [features/calendar.md](features/calendar.md): the calendar feed and the
  calendar view.
- [features/customising.md](features/customising.md): themes, density, saved
  views, keyboard shortcuts, logos and language.
- [security.md](security.md): signing in, the audit log, active sessions, and
  the security model.

## Building on it

- [api.md](api.md): the API, from tokens and the contract to every endpoint.
- [development.md](development.md): commands and tests, how it fits together,
  how costs are normalised, the front-end build, the design system, the
  application shell, adding a language, and refreshing the screenshots.
- [history.md](history.md): what each phase built.
- [phases/](phases/): every phase's brief. `phases/PHASE.md` is the current
  one.
- `images/`: the screenshots the README shows.
